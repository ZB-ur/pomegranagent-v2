## 接入边界

- 主持人（陪伴交流的角色）与饲养动物（儿童实际照顾的对象）需分别抽象；后续预设包括鸭鸭、虎皮鹦鹉、金丝熊。运行时共享配置位于 `web/diary-themes.mjs`，开始对话前切换，草稿和记录保存主题标记。
- 新角色独立图为 512×512 RGBA PNG，原始图集为 1254×1254；四态横图为 2048×512，顺序为 idle/listening/speaking/happy。独立图实际主体细节约 280–420 像素，未放大，不是高清母版。
- 现有鸭鸭使用暖色实底及专用 CSS 裁切；新增素材采用透明背景。接入时需检查实际组件大小、裁切、混合模式及姿态切换，不能只换文件路径就视为通过。
- 包内没有鹦鹉或金丝熊音频、配色配置或对话提示词；当前运行时使用主题配色与主持人上下文，音色/语速沿用教师设置，三套装修分别使用对应的柔和随机音效。
