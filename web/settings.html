正在检查

录音识别和中文播音都在本机完成，无需语音 API 密钥。只有识别后的对话文字会发送给 DeepSeek 接话与整理，照片和教师备注不发送。

请先听一听，再亲口讲一段虚构内容。

说完后按“停止录音”。思考或停顿不会自动提交；这里的结果仍需你对照实际声音判断。

每次聊几轮

默认 3 轮，可设 1–20 轮。幼儿说一段、鸭鸭回应一次算一轮。对新开始的对话生效；最后一轮先回应内容，再说结束语并进入核对。幼儿也可以提前结束。

鸭鸭怎样接着聊

DeepSeek 根据本次发言和对话上下文回应。对话需要联网，费用由服务商按 API 用量计收。

带走资料，也能找回来

完整备份包含档案、照片、排班、已识别草稿及记录，不含服务密钥。未识别的暂存录音还在原浏览器，请先完成识别。恢复前会保留当前资料的备份。
