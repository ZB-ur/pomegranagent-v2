# Pomegranagent V2 · 鸭鸭日记本

**让孩子自然讲述照顾动物的经历，让老师留下忠实、可回看的记录。**

这是一款在教师电脑上运行的幼儿交流与记录应用。教师准备幼儿、动物和当天名单，孩子选择自己的大头像，用空格键和日记本朋友聊一聊；主持人随教师装修，故事自动保存，教师随后核对、修改和备份。

**上一交付版已于 2026-09-09 获用户验收通过；本轮对话优化进入验证，整体效果尚未验收通过。** 这是独立开发的 V2，正式应用与历史交互原型分别保留。具体设备实测范围见下方[验收与运行环境](#验收与运行环境)，用户验收结论不代替未记录的平台实机结果。

## 当前声音：Qwen 好奇女孩（2026-11-17）

用户从本地试听中选定“好奇女孩”。正式播音已替换为 Qwen3-TTS 1.7B Base，固定使用随项目附带的合成参考音频。默认沿用试听轻快版：整段平均约 3.55 汉字/秒、保持音高的变速与 -23 LUFS 音量对齐；变速范围限制在 0.75–1.4，不能保证每句话恰好达到目标。MyEval 已确定的对话提示词与措辞不在本轮修改范围。

每次回复整段合成，不再分句、前瞻或排队生成。识别→接话→合成共用一次等待：超过 800ms，从随包附带的 10 条短提示中随机播放一条，避开上一条；每条 1.39–1.96 秒。回复就绪时等当前短提示自然结束再播，失败、退出、换人会停止旧播放与合成。17 条常用引导和安全退出提示也已预生成，模型忙时仍可播放。后端只有一个合成槽位，其他窗口的实时请求会得到明确忙碌提示，不积压旧回复。

Mac 使用 MLX 4-bit；Windows x64 + NVIDIA 使用独立 CUDA/PyTorch 环境和官方 Base 权重，共用同一参考音色。安装/运行代码、参考音频、预生成音频、版本与文件校验清单均在项目内；运行不依赖 `.acceptance` 或个人模型缓存。权重位于被 Git 忽略的 `models/`，完整离线发行包将权重、Python 和依赖一起携带。语音推理不访问云端语音 API。

本机集成检查使用 M1 Pro / 16GB：一条冻结 MyEval 回复生成 15.17 秒音频，完整合成与后处理 5.91 秒；单次实测，不能当作稳定时延承诺。活动合成取消约 22ms，随后可重新加载生成；模型忙时固定退出提示约 1ms 取得。10 条等待音频经本地辅助转写逐字匹配，仍需人耳判断。Windows / RTX 4060 尚未实测。

在 `8787` 隔离虚构资料中，实际 Chrome 操作完成真实新 C 接话→Qwen 整段播放→固定收尾→自动保存，SQLite/HTTP 读回一条记录、原话一致、`summaryFallback:false`。长语音准备中按 Esc 返回选人，合成进程已停止、草稿保留、没有新增记录。旧验收服务配置最初接话失败，换用本轮 MyEval 已用的运行时配置后通过；没有把该失败记为成功，也没有修改正式资料或打包密钥。

Mac 离线包已解压到独立目录，用包内 Python 与两组依赖，在操作系统禁止所有网络、禁止读取原项目模型/虚拟环境/原 Python 的条件下，完成实际 Qwen 合成和 SenseVoice 识别。该次冷路径约 44 秒（含首次加载、依赖初始化和识别，不是单次回复耗时）。证据保存在 `.acceptance/qwen-integration-20261117/`；真实儿童声音、设备听感与 Windows 仍待验收。未新增单元测试。

旧动物音效试听入口 `/animal-call-preview.html` 保留，叫声是预录文件，语音正文使用新的本地声音。

## 当前默认：新 C 日记本朋友（2026-11-13）

普通 `server.py`、`launch.command` 和 `launch.bat` 启动默认使用 `reference-companion-v5` / `5.0.1`；唯一默认值位于 `backend/agent_profiles.py` 的 `DEFAULT_DIALOGUE_PROFILE`，服务未提供 `ai_options` 或未指定 `dialogue_profile` 时也走同一路由。聊天一次生成，完整提供冻结的八段原创虚构多轮示范；整理独立调用，只输入本次儿童原话。提示词、示范、`relevant-same-child-v3` 历史选择和整理约定保持原评测版本，没有继续优化提示词。示范不是教师金标，也不代表当前儿童经历。

新 C 允许贴合情境的拟人化、美好想象和自然欣赏，分清现实动作、纠正、未完成打算与安全边界，不要求每轮复述或贴表扬标签。主持人取自教师装修，与实际动物分开；沿用现有录音、播音与叫声逻辑。历史按相关性选最多三篇同一幼儿的合格记录，无关时留空；历史池仅在内存驻留期间固定，重启或缓存淘汰后会重建。非收尾轮按需最多问一个问题，末轮及明确停止不追问；默认 3 轮和应用收尾保存流程不变。详见[产品约定](docs/product.md#真实-ai-接话与忠实整理)。

用户已选择新 C 的产品风格；先前虚构情境评测没有教师评分，不能据此宣称泛化或真实儿童体验已通过。本会话负责默认接入和语法、差异检查；真实 HTTP、连续浏览器操作、保存读回、重启持久化与实际性能统一由 MyEval 主会话验收，结果不以启动成功代替。

本次集成另加应用结束控制：主会话实际浏览器发现模型对“我讲好了”返回未结束。现在将最后一段儿童原话末尾的“我讲好了／我说完了／今天不聊了”等明确当下结束表达交给应用收尾，并在模型请求前禁止追问。也接住“我讲好了，但是我还要接着画”这类随后明确继续绘画、涂色、积木或手工的有限表达；同一活动之后明确延后的“画完再告诉你”仍按当下结束处理。后续要立即继续说话、否定、完成其他活动、引号内或带过去/转述前缀的表述不因包含关键词而触发，也不把单独出现“再告诉你”当结束。这是完整末尾句段匹配的有限规则，其他表达仍由模型理解；按钮结束保持原行为。该控制不是冻结提示词的一部分，原 192 个 trial 的成绩不证明新增控制后的全部行为。

开发检查：`python -m py_compile backend/app.py backend/agent_profiles.py backend/dialogue_v3.py backend/friend_profiles_v5.py server.py` 与 `git diff --check` 通过。普通启动在隔离空资料目录打印了新 C / 5.0.1，随后停止；没有接触正式资料。本会话快照和相对差异位于忽略目录 `.acceptance/new-c-default-20261113/`。

## 历史 baseline：对话理解与内部恢复（2026-10-26）

以下保留旧 baseline 的实现和当时验证边界；其两阶段接话及最近三篇快照规则不再是普通启动的默认方案。

本轮接入同一幼儿最近三篇故事与动物名字/类型的背景快照，排除其他幼儿、未来活动日及本篇建立之后的记录；已核对正文与未核对原话区别标注。单篇背景超过 6000 字时整篇省略正文，保留该篇日期和核对状态；旧残缺快照同样不再发送残缺事实，不用更早篇目补位，原始记录保持不变。不发送照片或教师自由备注，整理仍只依据本次原话。每轮保留鼓励或接纳，去掉强制长回复，不新增澄清问题或轮次。识别传输错误、对话服务瞬态故障及空白/无效 JSON 进行有限内部恢复，不增加轮次或重复保存；增加不含原文/录音的识别耗时与模型用量、结束原因诊断。

模型继续仅使用 `deepseek-flash`、thinking enabled / low、每次 4096 输出预算；整理 disabled / 2048。单次接话生成经过陌生样本审核仍出现补动作、次数、独立性及评价标签；同提示词的 low/high 对照也没有证明升级可解决，因此未升级。当前实现候选生成后由独立系统提示的第二次 Flash low 调用审查并直接修订，儿童只收到最终回复。两阶段共用 75 秒剩余等待预算、socket 空闲超时及一次故障重试额度：正常两次、最多三次调用；前端仍在 90 秒结束等待，不保证远端计算立即停止。代价是每轮多一次调用和额外延迟，两阶段实际接口八条复核消除了此前转圈、次数和耐心标签等越界；随后四条陌生样本未新增具体事实或澄清，耗时 4.4–6.6 秒，仍有机械复述，尚不能判定教师体验整体达标。不叠第三层，保留为待教师试用的候选。比较材料位于忽略目录 `.acceptance/dialogue-optimization/`，不属于新增测试体系。

## 第一次使用

1. **检查设备与服务。** 在设置页填写自己的 DeepSeek 地址、模型和密钥；本项目已使用 `https://api.deepseek.com` 与 `deepseek-flash`（DeepSeek V4.1 Flash）接通，模型需在自己的服务账户可用。本机语音无需另外申请语音密钥。选择声音和语速，用成人讲述的虚构内容完成听说检查。
2. **建档。** 填写幼儿姓名、小名及清晰头像，必要时维护实际小鸭的档案。原图支持 PNG/JPEG/WebP，最大 12 MB，保存时裁切为 JPEG；HEIC/HEIF 请先导出为 JPG。
3. **安排今天。** 点日历日期、勾选幼儿并保存。可以提前排班，但儿童端始终使用电脑今天的名单。
4. **让孩子讲述。** 方向键选大头像、回车进入；空格停止引导并直接打开录音，就绪时播放短提示音，再按空格停止。识别后的发言写入本机草稿，再请求真实 AI 回应和本机播音。
5. **结束并留存。** 孩子表达结束、达到轮数或选“今天讲好啦”进入收尾。当前发言先完成处理与回应，再播固定结束语；没有待处理发言时直接收尾。播完小本子高亮倒计时 3 秒，自动保存为待教师核对记录。儿童无需核对文字；未达上限时可在倒计时内按空格继续，回车或点击小本子立即保存。
6. **教师核对与备份。** 到故事记录对照原话，修改并标记已核对；下载完整 JSON 备份。文本导出用于阅读，不能代替可恢复的备份。

## 服务与数据如何流动

```text
浏览器麦克风（空格明确停止）
  → 本机 SenseVoice 识别 → SQLite 文字草稿
  → DeepSeek 根据上下文回应 → 本机 Qwen 好奇女孩整段播音 + 偶尔预录鸭叫
  → 收尾后 DeepSeek 整理 → SQLite 记录 → 教师核对 / 找回 / 备份
```

| 部分 | 当前实现 |
| --- | --- |
| 界面与录音 | HTML / CSS / JavaScript ES modules；MediaRecorder |
| 本机服务与数据库 | Python 标准库 HTTP 服务、SQLite 事务与 revision 冲突保护 |
| 语音识别 | SenseVoice Small int8，sherpa-onnx CPU |
| 中文合成 | Qwen3-TTS 1.7B Base，固定好奇女孩参考；Mac MLX 4-bit / Windows CUDA，语速独立缓存 |
| 录音解码 | PyAV；无需全局 ffmpeg |
| 对话与整理 | DeepSeek Chat Completions；接话使用 JSON 格式返回内容和结束标记 |
| 姓名搜索 | 本地 pinyin-pro，不通过网络查询幼儿姓名 |

本机识别和合成没有按次语音 API 费用；DeepSeek 调用需要联网，费用由服务商按账户用量计收。不会用固定示例接话或浏览器 `speechSynthesis` 代替正式对话和播音。

- **原始录音留在本机。** 聊天发送本次对话、同一幼儿最多三篇相关故事的必要文字背景、幼儿称呼与动物名字/类型；独立整理只发送本次儿童原话。照片和教师自由备注不发送。
- **资料保存在 SQLite。** 包含档案、裁切照片、排班、文字草稿、原始对话和核对内容。教师修改整理结果不会覆盖原话。保存记录与移除对应草稿在同一事务内完成。
- **密钥只存本机设置。** 不回传前端、不进入备份、不写入日志；数据库没有加密，需妥善保管电脑和资料目录。
- **暂存录音不是长期音频档案。** 未识别片段保存在原浏览器 IndexedDB，录音中约每 4 秒保留已收到片段；识别和文字保存成功后清除当前待处理音频。重说会保留上一段备用，但没有历史原始录音库或完整录音导出入口。
- **失败时保留可恢复内容。** AI 接话失败可重试；整理失败以识别原话保存并提示教师核对；落盘失败停留页面，不说“记好了”。同时修改同一内容发生冲突时不直接覆盖。
