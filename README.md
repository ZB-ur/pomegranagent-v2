# Pomegranagent V2

正式开发已开始，当前是**真实对话与本机语音已接通的开发版，首期尚未完成验收**。原型完整保留在 `prototype/`，原有 `run.py` 不变。正式应用为 `web/` + `backend/` + `server.py`，语音依赖安装在项目 `.venv`，无需 Node 构建。

教师试用请阅读 [产品说明书（开发预览版）](docs/user-guide.md)，包含启动、听说检查、建档排班、儿童操作、教师核对、备份恢复和故障处理。现有[核心操作演示录像](docs/videos/v2-operation.mp4)（约 5 分 17 秒，虚构合成语音样本）；真人麦克风完整流程录屏仍待设备验收。

录屏实测（2026-09-08）：绕过不可用的 QuickTime 录制入口，使用 Chrome 原生点击触发标签页共享与 MediaRecorder，已导出 H.264/AAC MP4，原始 WebM 保留在本机，不纳入公开仓库。录像包含建档裁切、当天排班、儿童选择与样本草稿继续、末轮回应状态、保存、教师核对修改及重开找回；剪去长时间停留和导航排障，保留播音失败重试。合成音频实际经过本机识别与 DeepSeek，但样本草稿由开发接口准备，非儿童麦克风输入。录音轨只收到部分引导声，AI 播音段未完整录入，不能用视频证明音频可懂度或完整音画同步。

## 获取项目

```sh
git clone https://github.com/ZB-ur/pomegranagent-v2.git
cd pomegranagent-v2
```

仓库不包含 API 凭据、本机数据库、录音、模型和虚拟环境。首次运行需准备语音环境，并在应用设置中配置自己的对话服务。项目更名后，已有资料目录 `PenegranagentV2`、备份格式与原型存储键保留旧标识，避免影响旧资料的读取与恢复。

## 正式应用运行

需要 **Python 3.12（64 位）**。首次在 macOS 双击 `setup-voice.command`，Windows 双击 `setup-voice.bat`，下载本机模型并安装项目虚拟环境；完成后分别双击 `launch.command` / `launch.bat`。Windows 需预先安装带 `py` 启动器的官方 Python 3.12；Mac 可用 Python 3.12 或已有 uv，脚本不会修改全局配置。

```sh
# macOS：已准备语音环境后
.venv/bin/python server.py --open
```

```powershell
# Windows：已准备语音环境后
.venv\Scripts\python.exe server.py --open
```

首次下载约 528 MB，模型解压约 661 MiB；当前 Mac 虚拟环境约 108 MiB。准备时需要联网与足够磁盘空间，建议留 2 GB 供下载和解压。模型及许可证保存在项目 `models/`，SHA256 校验后安装；完整模型重复运行会跳过。启动服务后台预加载，首次使用可能稍等。

打开 <http://127.0.0.1:8768/teacher.html>。窗口保持运行，Ctrl+C 停止。只监听本机，不对外发布。若默认浏览器不是 Chrome/Edge，请复制地址到支持的浏览器；端口占用时用 `--port 8769`。不要同时打开多份服务使用同一个资料目录。

本轮验收运行的是隔离目录，**全部为虚构资料**：

```sh
.venv/bin/python server.py --data-dir .acceptance/data
```

正常启动默认资料路径：macOS `~/Library/Application Support/PenegranagentV2/`；Windows `%LOCALAPPDATA%\PenegranagentV2\`。SQLite 保存档案、裁切照片、排班、文字草稿、原始对话与核对内容。清理浏览器缓存不会删除这些数据库资料。`--data-dir` 可指定其他目录，不能放在公开的 `web/` 下。

## 第一次准备与实际路径

1. 在幼儿管理新增姓名、小名及必需的清晰照片；原图支持 PNG/JPEG/WebP，最大 12 MB。拖动或用滑块裁切为 320×320 头像。小鸭管理独立维护名字、照片和备注；归档保留历史。
2. 默认排班月历中选择日期、勾选一至多名幼儿并保存；支持日期定位、沿用上周同日及复制整周，已有名单保留。儿童入口始终展示**今天**，不会把未来排班日期当作今天记录。
3. 到 [设备、服务与备份](http://127.0.0.1:8768/settings.html) 录入 DeepSeek 对话地址、密钥与模型，做成人虚构内容的听说检查。已按用户选择接入 DeepSeek；当前运行的隔离资料目录已保存对话配置，正常资料目录仍需单独配置。本机语音不需要另开账号或语音密钥。
4. 儿童用方向键选头像、回车进入；空格播放启动引导后开始录音，录音就绪给提示音；再次空格明确停止。停顿不提交。F1 或小鸭重听，方向键选择操作，回车确认，Esc 返回；编辑文字保留原生键盘行为。
5. 明确停止后上传录音识别，文字写入 SQLite 后调用真实对话模型，返回文字通过真实播音接口朗读。对话保存 child / assistant 角色；一次最多一个自然问题的要求由模型提示约束，效果仍待真实验证。
6. 选择小本子主动结束，调用真实模型忠实整理；整理失败时保留逐字原话供核对，界面明确说明。儿童可继续补充、朗读、核对保存。教师在故事记录对照原文修改、确认，按幼儿/日期/状态查找，手动关联明确提到的小鸭，导出当前筛选的文本记录。
7. 在设置页下载完整 JSON 备份；选文件后显示恢复预览，确认恢复。恢复前会在资料目录的 `before-restore/` 自动留下原资料备份。恢复后的备份仍可再次导入，不包含服务密钥。

## 真实服务与数据边界

对话与整理调用 DeepSeek `/chat/completions`；语音识别采用本机 SenseVoice Small int8，中文合成采用本机 Kokoro v1.1 zh，通过 sherpa-onnx CPU 运行。PyAV 解码浏览器录音，不要求全局 ffmpeg。本机识别和播音没有按次 API 费用；DeepSeek 对话仍按供应商用量收费。默认中文女声，可在设置页选择并试听。

密钥只存本机 SQLite，不发到前端、不进入备份、不打印日志；数据库不是加密保险箱。原始录音只传给本机服务，识别后的对话文字发送给 DeepSeek 接话与整理；照片、教师备注不发送。不以浏览器 speechSynthesis 或模拟接话代替本机模型。

未识别音频暂存在当前浏览器 IndexedDB：约每 4 秒保留已收到片段，显式停止后先保存完整录音再识别；识别和文字保存成功后清除该待处理录音。重说时保留上一段备用音频。关闭、崩溃及浏览器对不完整录音的解码行为仍需目标浏览器验证，不能保证突然断电前最后数秒不丢。**暂存音频不在 JSON 备份中**，应在原浏览器完成识别后再迁移。当前不是逐字实时识别，屏幕在停止后显示识别文字。

服务失败不会使用示例接话；播音失败明确请教师协助，也不会在启动语音未播出时悄悄开麦。SQLite 版本冲突不覆盖其他窗口内容；请保留当前修改，重新打开最新资料后核对。记录保存与删除对应草稿在同一事务内完成，教师修改不能更改已存原始对话。

## DeepSeek 接入结果（2026-09-08）

按用户选择，本轮在 `.acceptance/data` 中配置 `https://api.deepseek.com`、`deepseek-v4-flash`。密钥只存该本机资料库，未写入源码或文档。采用非思考模式以减少等待；对话与整理分别限制输出长度。设置页区分对话、识别、播音的配置状态。

实际通过应用后端调用 DeepSeek，使用人工输入的虚构文字，没有模拟模型：首条回应约 0.9 秒；初次纠正与结束检查发现猜测情绪和保留旧说法，修改提示后同一情境复查：回应接受结束且不再追问，整理采用“老师添水”的纠正。只验证这组样本，不代表儿童语音、所有模型行为或完整闭环已通过。

官方当前公开接口未列出语音识别/合成，本密钥没有用于其他供应商。识别与播音已改为本机模型。[DeepSeek 接入文档](https://api-docs.deepseek.com/)；[非思考模式参数](https://api-docs.deepseek.com/api/create-chat-completion/)。阶段账号周额度已用 22%，约剩 78%。

## 体验

默认“示例体验（不录音）”。先用方向键选择今日排班中的大头像，按回车进入该幼儿的对话：

1. 选择幼儿后听到点名与开场提示；画面持续显示当前幼儿。
2. 按空格，听完简短提示后进入倾听；示例文字会出现。
3. 再按空格，停止这次输入，鸭鸭接话。停顿不会自动提交。
4. 继续按空格可以再讲；点带小本子图标的“今天讲好啦”进入记录页。
5. 方向键选喇叭或保存按钮，回车执行；保存后回车返回今日名单。

常驻小鸭可重播当前引导。首次自动播音可能被浏览器拦截，点小鸭或开始按钮可激活。正在输入时不播放提示，以免把系统声音当成儿童发言。

教师体验区可切换“麦克风体验”。它使用浏览器的 SpeechRecognition，需要浏览器支持、系统麦克风权限和可用的识别服务。部分浏览器会把声音发送到厂商的识别服务；这不是离线语音方案。当前对真实发言的回复是固定引导，不代表 AI 已理解内容。

语音引导使用设备提供的中文 speechSynthesis 声音，优先选择本地中文语音；声音质量和可用性取决于电脑。真实使用前需用目标电脑实际听、说验证。

草稿和记录保存在当前浏览器 localStorage，清理浏览器数据会删除它们。当前用于虚构演示和成人测试，已有原型身份关联，尚无正式数据库与备份。

- **排班日历**：完整月历、月份切换、回到今天、日期定位；点日期后在右侧勾选幼儿并保存。方向键可跨日、跨周、跨月定位，回车进入名单编辑。可以沿用上周同一天的名单，或复用整周；整周复用预览新增与保留天数，仅填入空白日期。
- **幼儿与小鸭档案**：新增、编辑、搜索、照片上传/预览/移除、归档筛选与恢复。照片当前使用居中适配，尚无手动裁切。照片保存在当前浏览器，单张限制 2 MB，总容量受浏览器配额约束。
- **故事记录**：读取儿童端保存的真实原型记录，按幼儿与核对状态筛选，对照原始对话编辑并确认。

初始姓名、插画和月内排班均为虚构样例。数据保存在 `penegranagent-v2:prototype:management`，与儿童端草稿和记录联动。旧版未关联身份的示例仍保留在故事记录中。未来日期入口明确标为预览；记录带活动日期。原型没有接入正式数据库、AI、小鸭自动关联或备份恢复。
