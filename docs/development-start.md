# 启动 V2 后续开发

在 Codex 中把本目录作为独立项目打开，并从本目录新建开发会话。交互原型已确认，正式应用尚待开发；不要再从空白需求访谈或 V1 重构开始。

## 模型与配置

项目 `.codex/config.toml` 只固定 `gpt-6-astra` 与 `medium`，未设置全局插件、权限、额外 MCP 或自定义 agent 角色。子任务分工和推理建议放在 AGENTS.md，派发时按当前工具能力选择。

以周限额内完成首期为预算目标：主智能体 Astra / medium，复杂状态、架构取舍与阻塞诊断按需用 Astra / high；边界清楚的独立实现可试用 Sol / medium。通常不派发或只派发 1 个子智能体，小任务直接完成。降级任务出现实质性理解偏差或反复返工时由 Astra 接手，后续同类任务不继续试错。暂不默认加入 Terra/Luna，也不常态使用 xhigh/max/ultra。比较包含交接、审核与返工的总消耗，不以 API 标价推算订阅额度。

每完成一个可体验阶段读取一次可用额度，结合已完成范围校准后续计划；预留剩余额度约十分之一用于人工反馈后的修复与最终验收。周额度为账号共享，不能保证固定工作量；预期超出时提前说明，不擅自削减已确认范围。

配置文件存在不代表当前会话已切换设置；以新会话的实际模型、推理选项和工具能力为准。项目配置需要客户端信任该项目；显式运行参数可能覆盖项目默认。本次查到终端 CLI 为 0.113.0，不据此推断桌面应用版本；未加入依赖新版本的复杂子智能体配置字段。

依据：[Astra 模型指南](https://developers.openai.com/api/docs/guides/latest-model)、[Codex 子智能体](https://learn.chatgpt.com/docs/agent-configuration/subagents)、[项目配置与优先级](https://learn.chatgpt.com/docs/config-file/config-basic)。分级方案是本项目建议，不是官方固定路由规则。

## 可直接发送的初始 prompt

```text
请在当前 pomegranagent-v2 目录开始首期正式开发。这是独立开发的 V2，儿童端和教师端的交互方向已经确认。

先读取 AGENTS.md、docs/product.md 和 README.md，运行并实际查看 prototype 中的儿童端与教师端，理解已确认的交互。将原型作为体验基线，自主选择正式技术栈与代码结构。保留当前原型便于对照；不要修改 V1、全局配置或持久记忆。

目标是教师能在一台电脑上管理幼儿与小鸭、按日历安排一至多名幼儿，幼儿选择大头像后用键盘与鸭鸭自然交流，形成忠实记录，教师能核对、修改、找回并备份。首期不含“今天”汇总页、AI 打分与成长评价。

首期必须支持 macOS 和 Windows，技术选型、启动、设备权限、键盘操作、中文听说及数据存储均考虑两端。明确具体支持版本与运行环境，分别记录实际验收结果；无法访问的系统标为待验收，不能凭单端通过声称双端兼容。

幼儿端必须接入真实对话 AI，根据幼儿本次语音输入与当前对话上下文，生成并播出简短中文回应，必要时一次问一个自然的问题。支持补充、纠正和主动结束，不强制轮数、不诱导编造；固定操作提示与模拟接话不能代替这一能力。记录区分幼儿原话与 AI 发言。

幼儿识字能力有限：每个需要理解状态或行动的步骤都必须有简短、可重听的中文语音引导；全流程可用键盘完成，空格启停一段语音，停顿不自动提交。语音、屏幕反馈和常驻动态 IP 要一致。不能用文字提示或模拟服务替代真实听说体验的验收。

你对产品完成度、交互品质和整体交付负责。先提出简短的实施顺序与关键技术取舍，然后直接开始实现第一条完整路径：教师建档排班 → 一位幼儿真实语音与 AI 对话 → 教师核对 → 持久保存并重新打开。打通后继续完成首期范围，按实际结果调整实现，不需要每个步骤重新审批。

请在有独立任务且预计能改善速度或质量时派发子智能体，遵循 AGENTS.md 的分工与推理建议；主智能体继续推进其他工作并负责整合。模型和客户端设置以实际可用能力为准，不虚构已生效的配置。

首期不新增单元测试，不采用 TDD，不搭建或扩充自动测试体系。保留必要的构建、类型或语法检查与日志排查。验收以 Astra Computer Use 在实际应用中的操作结果和我的人工反馈为准：每次只验证受影响路径及关联关键行为，可交付阶段再走完整核心流程，不反复巡检未改动且已通过的页面。已有原型测试保留为历史参考，不作为完成门槛。

尽早验证真实语音、AI 和数据持久化，避免到页面全部完成后才接服务；验收使用隔离的虚构资料。界面状态和模拟服务不能证明实际音频可懂度、儿童语音识别与真实服务可用。每个可体验阶段给出运行入口和实际截图，说明已验证内容及仍需我在目标设备听说或儿童试用的部分。

以周限额内完成首期为预算目标，遵循 AGENTS.md 的额度检查与预留建议。先打通第一条真实完整路径，再按实际进展与总消耗调整分工；预期无法在额度内完成时提前说明，不擅自删除已确认功能。

需要我决定的目标设备、年龄范围、应用内模型/语音服务或凭据，请先从现有项目资料中查找；缺失时集中提出最少的问题，同时继续不依赖答案的开发。普通、可逆的实现选择由你决定，不增加未确认的产品功能。

现在开始。
```
