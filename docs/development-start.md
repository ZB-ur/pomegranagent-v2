## 当前体验约定

- 儿童只需大头像选人、听引导和空格明确启停录音；停顿不提交。
- 默认最多 3 轮，教师可设 1–20 轮；支持主动结束、补充与纠正。
- 无儿童核对页：动态回应后固定收尾，播完倒计时 3 秒自动保存，教师事后核对，下一位不受核对进度阻塞。
- 真实 DeepSeek 接话与整理、本机 SenseVoice/Kokoro 听说，不能用模拟服务证明真实能力。
- AI 保留具体鼓励，随机 35% 柔和预录鸭叫，不逐句朗读文字口癖。操作提示和日记朗读不插入音效。
- Windows 与未访问的 Mac 型号仍须分别记录实机结果，不把用户总体验收扩写为所有系统通过。
