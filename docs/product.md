# 鸭鸭日记本 V2：让孩子愿意说，也说得完

上一交付版于 **2026-09-09 获用户验收通过**；当前增加基于一线反馈的语音节奏、具体回应、新姿态与排班已选区优化，等待新一轮真实儿童试用。本文描述正式应用已确认的产品范围与交互约定；运行命令、素材展示和分平台实测边界统一见 [README](../README.md)。`prototype/` 是保留的历史体验基线，不以其中的模拟服务或旧儿童核对流程定义当前产品。

## 用户与目标

教师在一台电脑上管理幼儿、小鸭和排班，幼儿依次用语音讲述照顾小鸭的经历，教师能够核对、修改、重新找回并备份记录。V2 独立开发，不继承 V1 的全部功能或流程。

儿童识字能力有限，核心操作以简短、可重听的中文语音引导、大头像、图标和直观状态完成。教师可以在旁协助，但儿童无需阅读或核对整理文字，也无需等教师完成核对才能让下一位开始。

首期目标平台为 macOS 与 Windows，覆盖启动、权限、中文听说、键盘、档案排班、持久保存和备份恢复。不同系统和架构分别记录实测结果；用户总体验收不意味着没有访问过的 Windows 或 Intel Mac 自动通过。

## 完整使用路径

教师建档与设备检查 → 保存今天一至多人的排班 → 儿童选择自己的大头像 → 听一句欢迎问题 → 空格开始一段录音 → 再按空格明确停止 → 识别、保存原话、真实 AI 接话与播音 → 继续补充或进入收尾 → 收尾播音后倒计时 3 秒自动保存 → 下一位幼儿 → 教师事后核对与备份。

空格控制一段语音的启停，思考停顿不自动提交。录音采用 MediaRecorder，停止后在本机识别；屏幕不显示逐字实时转写。输入过程中不播放会被麦克风收进去的引导，按空格会停止欢迎或操作引导并直接申请/开启录音，真正就绪后只播放短提示音。

## 教师准备与管理

| 模块 | 当前范围 |
| --- | --- |
| 幼儿档案 | 姓名、小名、可选数值学号、必需的清晰头像、可选备注；新增、编辑、搜索、归档与恢复。儿童端以小名显示和称呼。 |
| 小鸭档案 | 实际饲养小鸭的名字、照片及备注；新增、编辑、搜索、归档与恢复。实际小鸭与戴眼镜的陪伴 IP 分开。 |
| 排班日历 | 完整月历、日期定位、当天多人选择、沿用上周同日、整周复用；只填入空白日期，保留已有安排。 |
| 故事记录 | 按日期、幼儿、核对状态查找；对照原始对话修改整理文字，手动关联明确提及的小鸭，标记已核对、导出当前筛选。 |
| 设备与备份 | 配置对话服务、检查本机听说、选择声音与语速、配置新对话轮数、下载与恢复完整备份。 |

教师默认进入排班日历，无“今天”汇总页。桌面端保留左月历、右单日编辑，紧凑顶部工具栏，右侧约 350px；已选名单默认两行，候选列表独立滚动，保存与补录并排固定在底部。顶部统一“复用安排”菜单：沿用上周同日名单作用于当前日期，复制整周安排打开来源周与目标周设置；右侧不再重复入口。窗口宽度不超过 940px 时，点击日期或回车打开单日编辑抽屉，关闭时仍保护未保存修改。不增加复杂时段或自动轮班算法。日期格最多显示两名幼儿及总人数，更多名单在当天编辑区查看；六周月份允许纵向滚动，不能靠压缩格子隐藏姓名。

学号为可选正整数，不保留前导零，在未归档幼儿中唯一；留空可移除，恢复归档时也检查冲突。幼儿管理与排班支持完整学号精确搜索，记录的幼儿筛选选项显示学号。

单日名单可按完整学号、中文姓名、小名、拼音首字母或全拼筛选，忽略大小写和空格，支持连续姓名片段。搜索使用本地 pinyin-pro，不向外发送姓名。过滤不会改变已选名单，已选名单常驻搜索框上方，默认两列两行，超过四位通过“查看全部”浮层查看与移除，不挤压候选列表；标签可直接移除，保存操作保持可见。显示全部已选数及被隐藏的已选人数；Enter 到首个匹配项，Esc/清空恢复全部。多音字可能匹配多个读音，特殊姓名可直接用中文搜索。

档案与记录编辑有未保存保护，支持继续编辑、放弃或保存并关闭。归档是停用实体，历史记录保留，可恢复；首期不提供永久删除幼儿或小鸭实体的入口。

### 照片

幼儿使用教师提供的稳定照片辨认身份。原图支持 PNG/JPEG/WebP，最大 12 MB；按文件内容判断格式，不依赖扩展名或系统 MIME 声明。方形取景框支持拖动、缩放、键盘滑块调整，最终保存 320×320 JPEG 到 SQLite，随档案备份。

小鸭同样支持裁切，卡片用居中正方形照片，与裁切比例一致；未上传时用统一占位插画。清晰照片配合名字与教师备注辨认实际小鸭，不用 AI 生成不同外貌或自动识别归属。HEIC/HEIF 不在当前支持格式内。

## 儿童身份与独立记录

儿童入口默认读取当前电脑今天的已保存名单。教师可在排班日历选择过去日期，保存名单后点“补录故事”，进入对应日期的儿童入口；不允许未来日期补录。补录全程显示日期，开场询问那天的经历；返回今天需先保存草稿。一名幼儿也保留头像确认，多人维持大头像并滚动展示；方向键选人时读出称呼，回车确认。

选人时重新读取名单和草稿，避免旧页面进入已移出名单的幼儿。头像卡和对话身份条显示暖黄色学号标签，仍以姓名称呼幼儿。对话持续显示当前幼儿头像与姓名；草稿按幼儿与活动日期隔离，暂存录音按故事隔离，故事本有身份边界，不把其他幼儿的内容带入。

记录保存成功后显示“记好啦”，主操作是“下一位小朋友”，回到本次活动日期的名单，不自动跳到其他幼儿。教师未核对的记录不阻塞换人。完成的幼儿仍可再次选择自己，新建另一篇故事；故事本仅展示所选幼儿的记录，可朗读和查看分角色原文。

## 真实 AI 接话与忠实整理

识别后的本次发言和当前对话上下文发送给 DeepSeek，生成简短中文回应，有具体故事时可聊三四个短句，通常约四十到九十字；不知道、简单纠正或结束可更短。操作引导可以固定，基于内容的接话必须使用真实模型；服务失败不能用模拟回复冒充成功。

回应以朋友式闲聊接住幼儿的故事，允许自然感叹和鸭鸭自己的兴趣表达，不固定采用“复述＋认可＋提问”结构，有明确照顾行动、观察或补救尝试时给一句具体肯定，再自然接话；普通闲聊、纠正、不知道和结束不硬塞表扬，也不强行追问。认可真实的照顾行动和观察时融入聊天，不像教师点评，不套用“谢谢你告诉我”或“你留意到了变化”。纠正时只确认改正，不扩写新观察；也可以温和接受不知道或不想继续。不机械重复夸奖，不推断未表达的情绪、能力、品德或小鸭感受，不为凑轮数强行追问。必要时一次最多问一个具体、易懂、开放的问题；这些是模型行为约束，不能据此保证每次模型输出均无偏差。

整理仅依据幼儿原话，保留不确定性与后续纠正，也不因精简遗漏明确的观察或动作。不得把 AI 的问题、鼓励、猜测或操作提示变成记录事实。幼儿与 AI 发言分角色保存；教师编辑整理文字不会覆盖原始对话。明确提到实际小鸭才手动关联，不确定时保持未关联。

### 轮数与结束

- 默认最多 **3 轮**，教师配置 **1–20 轮**，只对新建对话生效；恢复草稿沿用开始时设置。幼儿成功识别的一段发言计一轮，开场、重听和失败重试不额外增加。
- 幼儿表达“说完了”“不想说了”等明确结束意愿，模型判断结束；达到轮数上限由程序收尾。否定结束、讲述他人说结束或只是“不知道”不应被当作结束意愿。
- 当前发言先获得正常的动态回应；末轮不再提问。随后应用播放固定收尾：“你的故事讲好啦，我帮你记下来。”固定操作提示不作为新的对话事实写入原文。
- 也可主动选择“今天讲好啦”。录音中选择会先停止、处理当前段并回应；没有待处理发言时直接进入收尾，不额外发起无内容接话。
- 收尾播音完成后，小本子高亮并倒计时 **3 秒**。无操作自动整理并保存为待教师核对记录；点击小本子或按回车立即保存。未达上限可在倒计时内按空格继续，达到上限不再开启录音。
- **儿童没有核对页。** 整理失败保存识别原话并提醒教师；落盘失败留页重试，不提前显示完成。成功后再说“记好啦”。

### 精简语音流程

选人只说“找到自己的头像，来和我聊聊吧”，移动选择只读小名。进入对话称呼小名后问今天与小鸭做了什么；空格直接开启，录音期间不插话。停止后的短等待不播报，识别、接话及首句声音准备共用一次 5 秒等待提示；真正回应开始即停止该提示。错误和安全退出仍有语音帮助。

“怎么操作”提供可重听的完整键盘说明，帮助内 F1 重听、Esc 返回；平时 F1 或点鸭鸭重听当前话语。收尾继续沿用播音后 3 秒自动保存，成功后简短提示“记好啦！请下一位小朋友来吧”。

## 声音、文字和 IP

采用暖色 2D 绘本风格，常驻白鸭、黑色圆框眼镜、橙色嘴脚和暖黄色日记本。左侧小鸭陪伴，右侧呈现当前话语和大操作按钮；增加认真倾听、点头接纳、低头写日记、邀请开口四个姿态；图片预加载，保留原有说话与完成形象，状态轻柔过渡。听、说、等待、完成各有状态动作，尊重系统减少动态效果设置。

| 状态 | 需要儿童理解的内容 |
| --- | --- |
| 进入与选人 | 如何找自己的头像、当前选中谁、如何确认；空名单时请教师帮助。 |
| 对话或草稿恢复 | 鸭鸭知道自己是谁，接着聊什么，下一步怎样开始。 |
| 准备与录音 | 空格停止当前引导并打开麦克风，短提示音表示就绪；再次空格停止，停顿不结束。 |
| 停止与等待 | 收音已停止，正在识别或准备回应；较长等待有简短提示。 |
| 回应与继续 | 按句同步播出内容；结束后以邀请姿态和空格图示交还操作，不重复播操作教程。 |
| 收尾与保存 | 听收尾后自动记下，未达上限可继续；只在落盘成功后说记好了。 |
| 换人或失败恢复 | 成功后选择下一位；失败保留已有内容，语音不可用时明确请教师帮助。 |

正文按实际播放开始逐句显示，不提前展示整段，不承诺逐字字幕或音素级口型同步。当前句播放时提前准备下一句，常用引导预缓存。常规进入只播一句欢迎问题，普通回复后不重复操作教学；详细操作说明通过帮助按钮或 F1 重听。等待与播读锁定相关按钮和快捷键，避免儿童误触。

句间短暂停顿保持同一姿态，较长音频等待暂停动作，文本更新不重建 IP；实际输入和等待仍有各自状态。F1 或点击小鸭重听，提示替换旧提示而不积压。等待超过 15 秒提供带确认的安全退出，停止客户端等待并保留草稿/暂存音频，不标记完成。

教师可选音色及 0.85、0.95、1.05、1.15、1.25 倍语速，默认 1.05；修改后下一次播音生效，缓存区分声音与语速。

### 柔和预录鸭叫

采用用户选定的 qubodup「Duck Quack」柔和版，保留完整叫声，做降音量、柔化、淡入淡出，并在与正文衔接处留 90ms 空白。每条 AI 回复独立以 **35% 概率**加入一次，句首或末句句尾各半，不按固定次数补插。同一页面同一回复重听保持位置，刷新后可能重新抽签。

鸭叫由音频队列播放，不交给 TTS 朗读“嘎／嘎嘎”；正文在真正说出时显示，鸭叫期间 IP 保持播放状态。操作提示、固定收尾和日记朗读不插入音效。AI 不再被要求逐句生成文字口癖，但幼儿自己模仿鸭叫的真实表达仍应保留。素材的 CC BY 4.0 署名、原始来源和改动说明见 [正式音效目录](../web/assets/duck-call/README.md)。

## 技术和数据决定

正式应用采用 Python 标准库本机 HTTP 服务、SQLite 和原生浏览器模块，无前端构建步骤。录音用 MediaRecorder；本机 SenseVoice Small int8 识别、本机 Kokoro v1.1 zh 合成，经 sherpa-onnx CPU 与 PyAV 运行。应用内对话与整理使用用户配置的 DeepSeek；开发使用的模型不决定应用服务。

录音只发往本机，识别后的对话文字发往 DeepSeek，照片与教师备注不发送。密钥只存在本机 SQLite 设置中，不回传前端、不进入备份；数据库未加密。

补录以 activityDate 保存故事发生日，createdAt 保留实际录入时间；教师日期筛选和儿童故事本按活动日期展示。旧版仅按幼儿保存的草稿继续可读，在对应日期恢复保存时迁移为日期独立草稿，旧备份不含学号也可恢复。

SQLite 是档案和文字记录的正式来源，按 revision 检测多窗口冲突，避免直接覆盖同一草稿/记录。保存记录与移除对应草稿在同一事务内完成。图片直接存入数据库，避免图片目录与文字备份不同步。

未识别录音暂存在原浏览器 IndexedDB，按故事和录音段隔离；JSON 备份不含这些音频，不承诺长期原始录音留存、完整录音迁移或突然断电前最后数秒恢复。完整备份包含档案、照片、排班、已识别草稿和记录；恢复前自动保留旧资料备份。

## 范围外与后续验证

首期不包含 AI 打分、成长评价、排名、周期分析、“今天”汇总页、家长端、多园所、多角色账户、云端同步、移动端适配、自动轮班、复杂 3D 动画或 AI 照片识别。年龄范围、现场麦克风环境等尚未形成独立设备报告，不从开发样本推断普遍适用性。

开发采用必要语法/类型检查、日志排查和实际 Computer Use；不新增单元测试、不用 TDD、不扩充自动测试体系。原型测试保留为历史参考。日常只验证改动涉及的路径；上一交付版获用户验收；本轮优化仍需试用反馈，后续依新反馈和可访问目标设备补充听说、儿童试用及分系统记录，不反复巡检已通过且未改动的页面。

历史设计参考保留在交互中：月历导航、当日侧栏、多选后统一保存、整周复用与照片档案；原型中的浏览器识别、固定接话、浏览器存储和儿童核对步骤已由正式实现替代。旧阶段过程可通过 Git 历史追溯。
