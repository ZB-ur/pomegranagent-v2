# 鸭鸭日记 V2 · 教师使用说明书

版本：2026-09-09。当前版本已由用户确认验收通过，本文按已交付的正式应用编写。该确认未附具体系统、浏览器和儿童试用样本明细；Windows、Intel Mac 等未有独立实机证据的环境仍列为待验收。截图中的人物、故事均为虚构验收资料。

鸭鸭日记帮助幼儿讲述照顾小鸭的经历。教师负责准备档案与当天名单，幼儿选自己的头像、用空格键说话，再把故事保存下来。教师可以对照孩子原话核对、修改、查找和备份。首期没有“今天”汇总工作台、AI 打分或成长评价。

## 1. 准备这台电脑

拟支持 macOS 13–15（Apple Silicon / Intel 64 位）及 Windows 11 23H2/24H2（x64），使用 Python 3.12 和 Chrome / Edge 140+，窗口至少 1280×720。Windows、Intel Mac 和其他目标系统版本尚未完成实机验证。实际验收环境与结果见 [README](../README.md#验收与运行环境)。

首次准备需要联网下载约 528 MB 的语音模型，建议预留至少 2 GB 磁盘空间。对话 AI 使用 DeepSeek，需要联网及可用的 API 账户；识别和中文播音在本机进行，不另收语音 API 调用费用。

| 操作 | macOS | Windows |
| --- | --- | --- |
| 首次准备 | 安装 Python 3.12，然后运行 `setup-voice.command` | 安装包含 `py` 启动器的 Python 3.12，然后运行 `setup-voice.bat` |
| 日常启动 | 运行 `launch.command` | 运行 `launch.bat` |
| 浏览器入口 | `http://127.0.0.1:8768/teacher.html` | 同左 |
| 结束使用 | 完成保存后，在服务终端按 Ctrl+C | 同左 |

使用时保持服务终端运行。浏览器未自动打开时，手动输入上面的地址。不要直接打开 HTML 文件，也不要同时启动多个服务使用同一份资料。

当前开发演示服务使用 `.acceptance/data` 隔离资料；正常启动使用电脑的正式资料目录，两者不会自动同步。正式目录需要单独配置服务，也不会自动带入演示档案。

## 2. 先由教师检查听说

进入侧栏“设备、服务与备份”。

1. 确认“这台电脑的中文听说”显示模型已安装。若仍需准备，完成首次准备脚本，再启动服务并点“重新检查”。
2. 在“鸭鸭怎样接着聊”填写对话服务地址、模型及 DeepSeek API 密钥，点“保存对话设置”。已有密钥时留空会保留原值；保存配置不等于服务已实际通过。
3. 点“① 听中文引导”，亲耳确认中文清楚、音量合适。可选择“鸭鸭的声音”和“鸭鸭的语速”，点“保存声音和语速”后再试听。语速有 0.85、0.95、1.05（默认）、1.15、1.25 倍五档；按孩子听懂的程度调整。
4. 点“② 开始录音”，允许浏览器使用麦克风。亲口说一句虚构内容，例如“我看见小鸭走过来”，再点“停止录音并识别”。
5. 对照识别文字与实际发言，等待 AI 回应并亲耳听完。确认没有凭空增加孩子未表达的行动或情绪。

macOS 需要浏览器站点权限，以及系统“隐私与安全性 → 麦克风”中的浏览器权限。Windows 需要系统“隐私和安全性 → 麦克风”的设备/桌面应用权限，再允许浏览器站点录音。确认选中了实际使用的输入设备，扬声器和浏览器没有静音。

页面显示“播放结束”只能说明播放器收到结束事件，不能证明声音听得懂。请先由成人使用虚构资料检查，再安排儿童试用。用户已确认当前版本体验通过，但每台新电脑仍需完成麦克风权限和实际听说检查；开发环境的播放器状态不等于该设备已经通过。

## 3. 建好幼儿和小鸭档案

进入“幼儿管理”，点“添加幼儿”，填写姓名、小名，并上传一张清晰头像。儿童端使用小名显示和称呼。支持 PNG、JPG、WebP，图片不超过 12 MB；在裁切框内调整照片，使脸部清楚居中，再保存资料。教师备注可不填。

进入“小鸭管理”，填写小鸭名字、容易辨认的特征，可上传小鸭照片。这里管理实际照顾的小鸭；儿童端戴眼镜、抱日记本的鸭鸭是陪伴交流的形象。

需要停用档案时，打开“编辑资料”并归档。归档后不再出现在新的选择中，历史记录仍保留。选择“已归档”筛选可以找到档案并恢复。当前提供可恢复的归档，不提供永久删除档案的按钮。

## 4. 安排当天及之后的名单

默认首页是“排班日历”。点日期，在右侧勾选一至多位幼儿，然后点“保存当天安排”。看到“有修改，尚未保存”时，安排尚未落盘。

- 用上、下月按钮或日期输入框定位；“今天”按钮回到当天。
- 当天名单支持按姓名、小名、拼音或拼音首字母搜索，例如“林沐沐”可搜 `lmm`。搜索在本机完成，筛掉的已勾选幼儿仍保持选择；留意已选人数和隐藏已选提示。搜索框按回车进入首个匹配项，空格勾选，Esc 清空搜索。
- 月历单日显示最多两个名字及人数提示；多人详情仍在右侧编辑，不会挤占其他日期。
- “沿用上周同日的名单”先带入名单，检查后仍需保存当天安排。
- “复用一周安排”以周一为起点复制 7 天。先核对来源、目标及预览，再执行；已有安排的日期会保留。
- 月历获得焦点后，方向键移动日期，回车进入幼儿选择。

右上角“进入儿童端”始终进入电脑当前日期的名单，不会因为教师正在查看下周就让儿童记成下周的故事。日历可以提前排班，儿童入口只使用今天。

## 5. 幼儿和鸭鸭聊一聊

让孩子找到自己的大头像，用方向键选择、回车进入。已有草稿时可以继续；不同幼儿的草稿与故事分别保存。

| 想做什么 | 操作 |
| --- | --- |
| 选择自己的头像或当前操作 | 方向键选择，回车确认；也可使用 Tab / Shift+Tab |
| 开始讲一段话 | 按一下空格，等待引导结束和录音就绪提示，再说话 |
| 说完这一段 | 再按一下空格，明确停止收音 |
| 再听一次引导 | F1，或点击鸭鸭 |
| 返回、换人 | Esc，或页面上的返回/换人按钮；处理中需先等待 |
| 结束这次讲述 | 选择“今天讲好啦”，听完收尾后自动保存 |

停顿不会自动提交，不需要赶着说完。明确停止后，鸭鸭先识别，再结合本次内容与前文回应。孩子可以补充、纠正，也可以主动结束，默认最多 3 轮，教师可在“设备、服务与备份 → 每次聊几轮”设置 1–20 轮，对新开始的对话生效。说“说完了”等结束意愿、达到轮数，或选择“今天讲好啦”，都可以结束本次交流。最后一轮先正常回应，再接固定收尾引导，播完小本子高亮倒计时 3 秒，自动保存，不再开始下一轮。未达轮数而提前结束时，倒计时内可按空格继续说。点击小本子或按回车可立即保存。儿童不再核对文字，由教师事后核对。

回应准备和播放时，录音等相关操作会锁定，避免孩子连按空格误触；文字随对应语音片段开始播放而显示。鸭鸭会根据孩子实际说的内容给出具体鼓励，每条 AI 回复有 35% 概率在开头或结尾轻轻叫一次，不再每句话朗读“嘎／嘎嘎”。同一页面内重听这条回复保持相同位置；操作提示和故事朗读不插鸭叫。

结束后自动整理为待教师核对的记录。看到“记好啦”后，选择下一位；不必等教师核对，其他孩子就能继续交流。遇到服务失败，请保留页面并使用恢复操作，不把屏幕上的状态当作已经保存成功。

故事本只显示所选幼儿的记录，可以听故事、展开“对话原文”。原文分别标明孩子和鸭鸭发言。

## 6. 教师核对、修改和找回

在“故事记录”中按日期、幼儿、核对状态筛选。打开“核对原话”或“查看与修改”，逐项对照孩子和鸭鸭的对话原文，修改整理后的记录。只记录孩子确实表达过的内容，纠正说法应以孩子后来的说明为准。

明确提到了哪只小鸭才选择关联；不确定就保持未关联。点“保存并标记已核对”完成核对。修改整理文字不会改写已保存的对话原文。

保存失败时修改内容留在表单中。服务恢复后重试；若提示其他窗口也修改了同一内容，先复制当前修改，再重新打开最新记录核对，避免直接覆盖别人的修改。

“导出当前记录”导出当前筛选结果的文本，包含整理内容和对话原文。**文本导出用于阅读，不是可恢复的完整备份。**

## 7. 备份、迁移和恢复

在“设备、服务与备份”中点“下载完整备份”，保存生成的 JSON 文件。建议完成核对后备份，并在另一个安全位置保留副本。

完整备份包含档案、照片、排班、已识别文字草稿和记录；不含服务密钥，也不含浏览器里尚未识别的暂存录音。迁移前先在原浏览器完成录音识别。原始音频不是长期录音档案，不能用备份找回每段历史声音。

恢复时先结束其他页面的录音和编辑，再选择备份文件，核对预览里的幼儿数和记录数，最后点“用所选备份恢复资料”。恢复会替换当前资料；系统会先把原资料备份到资料目录的 `before-restore` 文件夹。恢复成功后回教师工作台查看。新电脑仍需准备语音环境并单独配置服务密钥。

默认资料目录（保留旧拼写以兼容已有资料）：

- macOS：`~/Library/Application Support/PenegranagentV2/`
- Windows：`%LOCALAPPDATA%\PenegranagentV2\`

使用指定资料目录启动时，以指定目录为准。不要手动编辑 SQLite 文件。清理浏览器数据不会删除 SQLite 中的档案和文字记录，但会影响浏览器暂存录音。

## 8. 出错时如何继续

| 看到的情况 | 下一步 |
| --- | --- |
| 页面打不开 | 确认启动终端仍运行，地址为本机 8768 端口；查看终端报错 |
| 模型还未准备 | 完成对应系统的语音准备脚本，重启服务，再点“重新检查” |
| 麦克风打开超时 | 检查系统与站点权限、输入设备，关闭其他占用设备的应用，再重试；超时不代表已录到声音 |
| 听不到引导 | 检查音量、静音和输出设备，点击重听；引导未成功播放时不要开始讲述 |
| 录音识别失败 | 使用“重试刚才的录音”；需要重说时按页面提供的保留上一段后重录操作，不先清缓存 |
| 对话没接上 | 检查联网、DeepSeek 配置与账户可用情况；已识别文字与 AI 回复是不同步骤 |
| 处理或准备声音超过 15 秒 | 可请老师点“等待较久 · 请老师安全退出”，确认“保留草稿并退出”；退出不标记完成，已保存文字和本浏览器暂存录音保留 |
| 保存超时或冲突 | 保留页面和修改，按错误信息恢复；冲突时先复制当前文字，再核对最新记录 |
| 备份文件无效 | 使用本应用下载的完整 JSON 备份；文本记录导出不能用于恢复 |
| 儿童入口没有头像 | 确认电脑日期、今天已保存的名单及档案是否处于启用状态 |

## 9. 验收记录与后续设备检查

2026-09-09，用户明确确认当前版本验收通过。此前开发检查覆盖教师建档排班、故事核对修改、按幼儿分开的故事本、持久保存、备份恢复等路径，并以合成虚构语音检查过真实识别与 DeepSeek 服务。开发中的合成音频通过后端送入，这项证据本身不证明浏览器能够真实收音。用户验收确认与开发检查分别记录，具体环境及截图见 [README](../README.md)。

新增或迁移目标设备时需要确认：成人和儿童亲口说话能否识别、停顿是否保留、空格停止是否可靠、回应是否自然忠实、声音是否清楚、设备中断后是否能恢复，以及对应系统上的完整保存与重开流程。Windows 和 Intel Mac 不能凭当前 Apple Silicon 环境的结果视为通过。

反馈时记录使用的系统、浏览器、当时操作、看到/听到的结果，以及是否重新打开后仍能找回。请优先使用虚构内容复现问题，不附服务密钥。
